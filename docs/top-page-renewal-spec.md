## 3. SCHOOL セクション（教室紹介のMAP化）

### 現状
- `templates/home.php` L286-327
- 背景写真＋見出し＋**エリアタクソノミー（`area`）のバナー一覧**（上位4件、件数表示、クリックで`/area/{slug}/`へ遷移）のみ
- **TOPページ上に地図表示は現状実装されていない**（Google Maps / Leaflet 等のライブラリ未導入）

### 【重要】既存の「教室紹介」管理画面（schoolカスタム投稿）は流用できる
`single-school.php` L25-71 を確認したところ、教室紹介の管理画面には既に以下のACFフィールドが存在する：

| 既存フィールド | 内容 | MAP化での使い道 |
|---|---|---|
| `googlemap_iframe` | Googleマップ埋め込み用iframe URL | 緯度経度を正規表現で抽出できる可能性が高い（Google埋め込みURLは`!3d..!4d..`形式で座標を含むことが多い） |
| `googlemap_link` | GoogleMapsを開くリンク | `@緯度,経度`形式で座標を含むことが多く、こちらも抽出候補 |
| `zipcode` / `address` | 住所 | ポップアップ表示、または座標抽出に失敗した場合のジオコーディング元 |
| `tel` | 電話番号 | ポップアップ表示 |
| タクソノミー `area` | 名古屋／尾張／三河／岐阜などのエリア分類 | 左側エリア別件数リストにそのまま流用可（現行のSCHOOLセクションでも使用中） |

### 【方針決定】座標は既存URLのパースではなく、新規フィールド追加で持たせる（本命案）
座標取得には2案あったが、比較の結果**新規フィールド追加を採用**：

| 方法 | メリット | デメリット |
|---|---|---|
| 既存`googlemap_iframe`/`googlemap_link`をパース | 追加の手入力ゼロ | URL形式がバラバラだと失敗する／Googleの仕様変更に弱い |
| **新規で緯度経度フィールドを追加（採用）** | 確実・保守性が高い・将来の校舎追加時も同じ手順 | 既存14校舎（名古屋6・尾張4・三河3・岐阜1）分は一度だけ手動で位置指定が必要 |

- ✅ **確認済み**：サーバーの`wp-content/plugins`に`advanced-custom-fields-pro`フォルダを確認。**ACF Pro導入済み**。
- ACF Proの「Googleマップ」専用フィールドタイプが使えるため、管理画面の地図上でピンを置く／住所検索するだけで緯度経度・住所をセットで保持できる（座標の手入力・パース処理いずれも不要）

**要確認**：
- [ ] 既存14校舎分の位置指定は誰が行うか（数分/件程度の想定）

一方、画像③のポップアップにある**「対象学年」「指導形態」「開校時間」は現行の管理画面に項目が無い**ため、これも新規追加が必要：
- 教室紹介（school投稿）にACFフィールドを3つ追加（対象学年／指導形態／開校時間）
- 既存の校舎データに対し、その3項目のみ追記してもらう（住所は既存のものをそのまま利用）

### 変更したい内容（参考画像③）
- 「東海エリアに展開中！」のような見出し＋エリア別件数リスト（名古屋／尾張／三河／岐阜など）を左側に配置
- 右側に**地図＋ピン表示**
  - ピンをクリック→教室名・エリア・対象学年・指導形態・開校時間・「詳しく見る」ボタンを含むポップアップカードを表示
- 「地図／リスト」の表示切り替えタブ
- 「現在地から探す」ボタン

### 要確認事項（これは新規機能開発になるため要相談）
- [ ] 地図ライブラリの選定：Google Maps JavaScript API（要APIキー・課金）か、Leaflet + OpenStreetMap（無料）か
- [ ] `school`投稿に**Googleマップ型フィールド**（緯度経度・住所を保持）＋**対象学年・指導形態・開校時間**の計4フィールドを新規追加
- [ ] 既存14校舎分、位置指定・対象学年・指導形態・開校時間の入力を誰が行うか
- [ ] エリア件数リストは現行の`area`タクソノミーをそのまま流用可能
- [ ] スマホ表示時の地図UI（画像③はPC想定に見える）

> **メモ**：ACF Pro導入確認済みのため、住所・エリア分類に加え緯度経度もGoogleマップ型フィールドで管理画面から直接入力できる。地図描画部分（ライブラリ選定・ピン・ポップアップ・エリア絞り込み）は新規実装。
